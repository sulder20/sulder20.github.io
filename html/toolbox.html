常见问题

数据保存在哪里？会不会丢？

不登录时，所有数据保存在你浏览器的 localStorage 中（键名以 suidou- 开头），刷新或关闭页面都不会丢失。

但清除浏览器缓存、更换设备 / 浏览器、使用无痕模式都会导致数据丢失，建议定期在「设置 → 数据管理」导出 JSON 备份。

换了一台设备，怎么把数据搬过去？

方式一（推荐）：注册并登录账号 → 在设置页点「上传本地数据到云端」→ 另一台设备登录同一账号后点「从云端拉取数据」。

方式二：在旧设备导出 JSON 备份文件，在新设备通过「设置 → 导入数据」恢复。

本地模式和云端模式有什么区别？

本地模式：数据只存在你自己的浏览器里，不上传服务器，无需登录，适合单设备使用。

云端模式：登录后数据同步到 Supabase，多设备共用同一份数据；AI 相关功能也只对登录用户开放。

右上角的徽章会实时显示当前所处的模式。

为什么 AI 功能提示「请先登录」？

AI 请求需要通过你的登录凭证转发到服务端进行鉴权和额度统计，因此必须先登录才能使用。

登录后每天有固定的免费额度，聊天页右上角会显示「今日已用 x / 20 次」。运动热量估算、健康数据分析、随机灵感 AI 生成、起名器等同样计入该额度。

AI 每天能用多少次？额度什么时候重置？

每个账号每天有固定的免费调用次数，AI 助手聊天页会实时显示今日已用次数。

额度按自然日重置，当天的使用量不会累计到第二天。

忘记密码了怎么办？

在登录页点击「忘记密码？」，输入注册邮箱后我们会发送一封重置密码的邮件。

如果没收到，请检查垃圾邮件文件夹；重置链接有时效，过期后可以重新发送。

怎么修改用户名和头像？

登录后进入「设置 → 个人资料」，可以上传头像（自动压缩到 180px 以内）和修改用户名。

用户名只用于主页右上角显示，不影响登录邮箱；未登录时这两项不可用。

上传的图片会不会占用很多空间？

所有图片在上传前都会自动压缩：头像 180px、人物图片 400px、小说封面 600px、地点 / 影视 / 运动图片 800px。

浏览器 localStorage 上限一般约 5 MB，可在「设置 → 数据管理」查看当前占用。建议不要一次性放入过多高清大图。

同时优化了二维码模块，修复了本地文件协议下的导出兼容性。

「健康管理」都能做什么？鞋码在哪？

BMI 计算：输入身高、体重（支持 cm / m、kg / 斤 / 磅）得到 BMI 数值、分级与理想体重区间。

鞋码计算：V2.3.1 从数学计算迁入，输入脚长（mm 或 cm）与年龄，会区分成人码与童码，同时给出中国码、欧码、美码、英码、日码推荐，并附带公式与完整对照表。

睡眠记录：录入入睡时间与起床时间，自动计算睡眠时长（含跨夜），按日期绘制近 30 天睡眠曲线，支持导出 PNG。

生命体征：可录入心率、血糖、血压（收缩压 / 舒张压），系统按参考范围自动标出「正常 / 偏高 / 偏低」，并可把一段时间的数据整体交给 AI 做趋势解读。

所有结果仅为生活参考，不构成医疗建议。

睡眠记录怎么算跨夜时长？

若起床时间早于入睡时间，系统会判定为跨夜，自动加 24 小时再相减。例如 23:30 入睡、07:00 起床，睡眠时长为 7 小时 30 分。

若入睡与起床时间完全相同，会视为 0 分钟并拒绝保存，请检查是否填错。

「运动记录」的热量估算准不准？

系统会先基于你填写的性别、年龄、身高、体重做基础代谢与运动代谢估算；勾选「让 AI 辅助估算」后，AI 会结合运动类型、时长、强度给出更细化的参考区间。

运动手环、心率带等专业设备的数据更准确，本工具结果仅供参考。

鞋码计算为什么需要「年龄」？

儿童与青少年的脚部仍在发育，同一脚长在成人码与童码中对应关系不同。输入年龄后，系统会区分成人码表与童鞋码表，给出更合理的推荐区间。

不同品牌、不同鞋型的尺码略有差异，建议同时参考具体商品的官方尺码说明。

「随机灵感」的 AI 生成会消耗额度吗？

会。本地随机（点上方卡片）不消耗额度，随时可用；AI 批量生成会调用一次 AI 请求，计入当日额度，且需要登录。

AI 每次会记下已生成内容，下次生成时自动避开，避免翻来覆去都是那几条。

「起名器 / 对话生成器 / 时间线 / 灵感速记」为什么不在 AI 助手里了？

因为它们的本质是创作工具，只是部分功能借助 AI 实现。V2.3.1 起它们归入「创作工坊」，与小说助手、人物印象表并列，入口更直观。

其中时间线和灵感速记完全不依赖 AI，本地即可使用；起名器和对话生成器需要登录后才能调用 AI。

歌曲收藏能直接试听吗？

不能。本工具只记录歌曲信息与歌词，并提供 QQ 音乐、酷我音乐、酷狗音乐、网易云音乐的搜索 / 直链跳转，播放需要到对应平台进行。

如果在「后台填写」里填了某平台的链接，跳转时会直接使用该直链。

日历为什么只能查看 2026 年 10 月到 2036 年 12 月？

这是当前版本设定的可查看范围，超出范围的月份在年份 / 月份下拉框中会被禁用。

点击「回到 2026-10」可以快速回到起点；点击某一天的格子即可查看、添加、修改或删除当天的安排。

代码编辑器安全吗？支持哪些语言？

JavaScript 模式运行在带有 sandbox 属性的 iframe 中，无法访问本页面的数据和存储，相对安全。

当前支持 JavaScript 实时运行 与 Markdown 实时渲染两种模式；仍建议只运行你自己信任的代码。

点了导出按钮却找不到文件？

所有导出（JSON 备份、CSV、docx、TXT、HTML、PNG）都通过浏览器的下载功能保存到默认下载目录。

如果没有反应，请检查浏览器是否拦截了下载、是否开启了「下载前询问保存位置」，以及手机端是否需要在文件管理器中查找。

误删或清空的数据还能恢复吗？

不能。工具箱不保存历史版本，已清空且没有备份的数据无法找回。

所以在执行「清空全部数据」之前，请务必先导出备份。云端模式下清空会同时删除云端记录。

页面显示异常、按钮点不动怎么办？

可以依次尝试：① 刷新页面；② 检查网络（AI 功能和云端同步依赖网络）；③ 换用 Chrome / Edge / Safari 等现代浏览器。

如果仍然异常，欢迎把浏览器版本和具体操作步骤反馈给我们。
