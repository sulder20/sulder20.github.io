## 这是什么

Pixel Arcade 是一个像素复古风的网页小游戏合集。

- **9 款游戏**：5 款经典 + 4 款原创
- **打开就玩**：不需要下载、不需要注册、不需要安装
- **电脑手机都能玩**：自动适配屏幕，支持键盘、鼠标、触摸
- **可以离线玩**：第一次打开后，断网也能继续玩
- **可以添加到主屏**：像 App 一样启动

整个界面是经典的 GameBoy 掌机风格：绿色调、像素字、CRT 扫描线。

## 怎么打开

### 最简单的方式

双击 `games.html`，用浏览器打开即可。

### 推荐方式

如果想让离线缓存和「添加到主屏幕」功能生效，需要用一个本地服务打开：

在项目根目录打开终端，运行：

```bash
python3 -m http.server 8000
```

然后浏览器访问：

```
http://localhost:8000/games.html
```

不熟悉命令行也没关系，双击打开的方式已经能玩全部游戏。

## 通用操作

所有游戏都遵循同一套操作习惯：

| 功能 | 操作 |
|---|---|
| 开始游戏 | 点击「开始」按钮，或按 `空格` / `回车` |
| 暂停 / 继续 | 按 `P` / `Esc`，或点击底部「暂停」按钮 |
| 重新开始 | 点击底部「重开」按钮 |
| 查看玩法 | 点击右上角 `?` 按钮 |
| 开关音效 | 点击右上角 `♪` 按钮 |
| 调节音量 | 点击右上角 `🔊` 按钮 |
| 全屏 | 点击右上角方框图标 |
| 返回主菜单 | 点击左上角 `←` |

**游戏中直接点左上角返回，会先弹确认框**，防止误触丢进度。

## 玩法详解

### 1. 贪吃蛇

**目标**：吃食物变长，活得越久越好。

**操作**
- 电脑：`← → ↑ ↓` 或 `WASD`
- 手机：滑动屏幕

**规则**
- 吃到食物 **+10 分**，蛇身变长
- 每吃一个，速度略微加快
- 撞到墙或自己的身体 → 结束

**技巧**：别急着转向，保持蛇头有退路。贴边走比走中间更安全。

---

### 2. 俄罗斯方块

**目标**：拼满整行消除，活得越久越好。

**操作**
- `← →` 左右移动
- `↓` 加速下落
- `↑` 或 `X` 顺时针旋转
- `Z` 逆时针旋转
- `空格` 直接落到底部
- `P` / `Esc` 暂停

手机底部有虚拟按键，长按可以连续移动。

**计分**
| 一次消除 | 得分（× 等级） |
|---|---|
| 1 行 | 100 |
| 2 行 | 300 |
| 3 行 | 500 |
| 4 行 | 800 |

每累计消除 10 行升 1 级，下落速度变快。

**界面说明**
- 左侧大框是棋盘
- 右侧 `NEXT` 是下一个方块预览
- 半透明轮廓是当前方块的**落点预告**（幽灵方块）

**技巧**：把方块集中在一侧堆高，另一侧留空，方便消四行拿高分。

---

### 3. 打砖块

**目标**：用球打光所有砖块。

**操作**
- 电脑：`← →` 或 `A / D`，也可以用鼠标左右拖动
- 手机：手指在屏幕上左右拖动
- 发射球：`空格`，或点击屏幕，或点「发射」按钮

**计分**
| 砖块位置 | 分数 |
|---|---|
| 最上一行 | 50 |
| 第 2 行 | 40 |
| 第 3 行 | 30 |
| 第 4 行 | 20 |
| 最下一行 | 10 |

**规则**
- 共 3 条命
- 球掉出底部扣 1 条命
- 打光全部砖块 → 自动刷新一轮，额外 +100 分
- 每打碎一块砖，球稍微加速

**技巧**：用挡板边缘击球，反弹角度更大，更容易打乱球路。

---

### 4. 2048

**目标**：合并相同数字，凑出 2048。

**操作**
- 电脑：`← → ↑ ↓` 或 `WASD`
- 手机：滑动屏幕

**规则**
- 每次有效滑动，随机出现一个 `2`（90%）或 `4`（10%）
- 相同数字撞在一起合并翻倍，得分 = 合并后的数字
- 合成 `2048` 即获胜，可以继续挑战更大数字
- 棋盘填满且无法移动 → 结束

**技巧**：把最大的数字固定在一个角上，其他数字往这个角推。不要频繁换方向。

---

### 5. 记忆翻牌

**目标**：找出全部 8 对相同图案。

**操作**：点击或触摸牌

**规则**
- 每次翻开两张
- 图案相同 → 配对成功，**+100 分**
- 图案不同 → 短暂展示后翻回，**-10 分**
- 全部配对完成，额外 **+200 分 + 时间奖励**（用时越短奖励越高，最多 +400）

**界面**
- `SCORE`：当前得分
- `MOVES`：翻牌次数
- `TIME`：用时

**技巧**：第一次随便翻，记住位置。后面靠记忆快速配对，减少翻牌次数。

---

### 6. 闪避方块（原创）

**目标**：躲开所有从上方落下的方块。

**操作**
- 电脑：`← →` 或 `A / D`
- 手机：手指左右拖动

**规则**
- 每躲过一个方块 **+10 分**
- 被任意方块碰到 → 结束
- 越往后：方块越大、下落越快、出现越频繁

**技巧**：不要贴边，保持中间位置。观察新出现的方块提前移动。

---

### 7. 颜色陷阱（原创）

**目标**：从 4 个相近颜色里，挑出与顶部完全相同的那个。

**操作**：点击或触摸色块

**规则**
- 顶部大色块是**目标颜色**
- 下方 4 个色块颜色相近，其中一个完全相同
- 答对 **+10 分**，答错 **-1 条命**
- 共 3 条命，用完结束

**技巧**：不要盯着看太久，越看越糊。第一眼直觉往往最准。

---

### 8. 节奏点击（原创）

**目标**：音符落到底部判定线时点击对应轨道。

**操作**
- 电脑：`A` `S` `D` 分别对应左、中、右三条轨道
- 手机：直接点击对应轨道

**判定**
| 判定 | 条件 | 得分 |
|---|---|---|
| PERFECT | 音符中心距判定线 ≤ 10px | +30 |
| GOOD | 距离 ≤ 22px | +10 |
| MISS | 距离 > 22px | 扣 1 条命 |

**Combo**
连续命中会累积连击，每 5 连击额外加分（最多 +50）。

**规则**
- 共 3 条命
- 空击（没音符时点击）只断连击，不扣命
- 越往后音符出现越快

**技巧**：跟着节拍，别盯着单个音符，看整体节奏。

---

### 9. 数字合成（原创）

**目标**：合并相邻相同数字，在棋盘填满前拿高分。

**操作**
1. 点一个数字**选中**它（再点一次取消）
2. 点**相邻的空格** → 数字移过去
3. 点**相邻的相同数字** → 合并翻倍

**规则**
- **移动**：数字移过去，并生成一个新数字（棋盘更满）
- **合并**：两个数字合并翻倍，并生成一个新数字
- 得分 = 合并后的数字值
- 棋盘填满 + 没有相邻相同数字 → 结束

**为什么每次都会生成新数字？**
为了让游戏有终点、有紧张感。你必须在棋盘填满之前尽量多合并。

**技巧**
- 优先合并大数字（得分高）
- 用「移动」主动创造相邻机会
- 不要留太多小数字散在角落

## 主菜单功能

主菜单是进入所有游戏的入口。

### 顶部
- 左：标题 `PIXEL ARCADE`
- 右：音量按钮 `🔊`、音效开关 `♪`

### 最近玩过
显示你最近玩过的 4 款游戏，一键直达。

### 筛选
三个按钮切换显示：
- **全部**：显示所有 9 款
- **经典**：只显示经典游戏
- **原创**：只显示原创游戏

### 游戏卡片
每张卡片包含：
- 右上角标签：`经典` 或 `原创`
- 像素图标
- 游戏名
- 历史最高分 `BEST xxxx`（如果玩过）

### 底部统计
- **已玩**：玩过的游戏数量 / 总游戏数
- **总次数**：所有游戏的游玩次数之和
- **总分**：所有游戏的最高分之和

### 重置按钮
`RESET DATA`：清空所有最高分和游玩记录。点击后会弹确认框。

## 设置说明

### 音效开关 `♪`
点击切换开 / 关。关闭时图标变成 `×`。设置会记忆，刷新后仍然生效。

### 音量调节 `🔊`
点击弹出音量滑杆，拖动调节。图标会随音量变化：
- `🔇` 静音或音量 0
- `🔈` 音量低于 40%
- `🔉` 音量 40% ~ 75%
- `🔊` 音量高于 75%

音量设置会记忆，刷新后仍然生效。

### 全屏按钮 `[ ]`
点击进入全屏，再点退出。手机玩游戏时推荐全屏，画面更大。

### 玩法说明 `?`
每款游戏首次进入会自动弹出说明，关闭后不再自动弹。想再看时点右上角 `?`。

## 常见问题

### 声音不响？

浏览器要求用户先和页面交互才能播放声音。随便点一下屏幕，再试一次。

如果还是没声音：
1. 检查音量按钮是不是静音状态（图标是 `×` 或 `🔇`）
2. 检查浏览器标签页有没有静音
3. 检查系统音量

### 手机横屏时显示「请竖屏游戏」？

这是正常的。横屏时操作区域太窄，游戏体验不好。转回竖屏即可。

### 游戏中途想返回主菜单，但弹了确认框？

这是防止误触丢进度。确认退出就点「退出」，想继续玩就点弹窗外关闭。

### 最高分怎么清空？

主菜单底部的 `RESET DATA` 按钮，点击并确认即可。

### 数据会不会丢？

数据存在浏览器的本地存储（localStorage）里，**不会上传到任何服务器**。

以下情况会丢数据：
- 清空浏览器数据 / 缓存
- 使用无痕模式（关闭窗口即清空）
- 换浏览器或换设备

### 能离线玩吗？

用本地服务打开一次后，断网可以继续玩。

`file://` 双击打开的方式不支持离线缓存。

### 可以添加到手机主屏吗？

可以。

- **iPhone Safari**：分享按钮 → 添加到主屏幕
- **Android Chrome**：菜单 → 添加到主屏幕

添加后能像 App 一样从桌面启动，全屏运行，没有浏览器地址栏。

### 支持哪些浏览器？

Chrome / Edge 90+、Firefox 88+、Safari 14+、iOS Safari 14+、Android Chrome 90+。

IE 系列不支持。

## 手机使用技巧

### 手势
- **滑动**：贪吃蛇、2048 用滑动控制方向
- **拖动**：打砖块、闪避方块用拖动控制位置
- **点击**：记忆翻牌、颜色陷阱、节奏点击直接点

### 虚拟按键
俄罗斯方块底部有虚拟方向键：
- 点一下移动一格
- **按住不放**会连续移动

### 防止误触
- 游戏中点左上角 `←` 返回会先弹确认
- 页面已禁用双指缩放和双击放大

### 横屏提醒
横屏时自动显示「请竖屏游戏」遮罩，转回竖屏自动消失。

### 添加主屏
推荐添加到主屏幕，好处：
- 启动更快
- 没有浏览器地址栏，画面更大
- 可以离线打开
- 有独立的像素图标

## 数据与隐私

### 存了什么

Pixel Arcade 只在你自己的浏览器里保存以下数据：

| 数据 | 用途 |
|---|---|
| 每款游戏的最高分 | 显示在卡片上 |
| 每款游戏的游玩次数 | 主菜单统计 |
| 每款游戏的说明已读状态 | 决定是否自动弹说明 |
| 音效开关状态 | 记忆你的偏好 |
| 音量大小 | 记忆你的偏好 |
| 最近玩过的游戏列表 | 主菜单「最近玩过」区块 |
| 开场动画是否看过 | 每个会话只显示一次 |

### 不会做什么

- ❌ 不上传任何数据到服务器
- ❌ 不收集任何个人信息
- ❌ 不使用 Cookie 追踪
- ❌ 不显示广告
- ❌ 不请求任何不必要的权限

### 想清空数据

- **只清游戏记录**：主菜单底部 `RESET DATA` 按钮
- **清所有数据**：浏览器设置里清空该网站的存储数据
