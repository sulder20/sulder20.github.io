Chapter 0 新的生活（共3868字）

「可是，有一些人总是活在当下；但未来总会到来，它不是像惊喜一样毫无预警，而是像明天一样如期到来；如果是你，你会怎么做？」
全书言

（萌学园，萨姆族事件结束三天后）
图书馆内，众人正在忙着自己的事情，看书的看书，查资料的查资料，做笔记的做笔记；
理科教室内，老师还在上课，讲台下的学生们听得十分认真，这里诞生过师生共研的舞台；
魔法练习场内，诸位正在为即将到来的阶段性考核做准备，练习魔法是这里的常态；
但，宿舍内，仍有部分同学，还在睡觉………
“焰王，欧趴，你们怎么还在睡觉啊，今天是毕业课题汇报，赶紧起来了。”
说话者正是谜亚星，他是和艾瑞克一起来的。他们整装待发，突然发现少了几位，于是便来到了焰王和欧趴的宿舍里。潼恩因为是女生，所以不方便，只能在穿堂坐着。
宿舍里面还有一个汉斯格雅正在呼呼大睡。

//本书主要设定：
《风卷骇浪》
以皮安领导的新型夸特诺基地小队为主要切入点，本篇（Chapter 0）是总体概括，时间线设定在萨姆族事件结束后，“萌骑士”等人即将迎来毕业课题，完成后经长老会核准，允许毕业。
每个人有每个人的未来与思考，新的故事总要开始。
其次，宇宙大同的到来也让他们意识到了“和平”成为了新的主要流行趋势。他们在工作中进步，在生活中学会新的技能。
同时，本书还有众多新的角色，他们各有各的本领，各有各的兴趣；此外，还保留了一些剧版的老角色，甚至还有神秘角色回归，与我们的主角产生新的火花，大家敬请期待！
为了方便理解，本书地点分为四个大区域：
地球区|以皮安为首的夸特诺基地小队（主要地点，主要情节）；
萌学园区|临近退休的诸位老师与新时代学生；
安理纳斯基地区|位于夸克星，是三位萌骑士的主要工作地点；
时安区|另外两位萌骑士的主要工作地点；
（营造神秘感，将不透露具体“萌骑士”名字）
宇宙会一直平稳下去吗？黑夸和平、宇宙大同时代下，他们还会有什么本领，去维持宇宙的和平呢？
//

帕主任在早上例行巡逻，巡逻到了穿堂。
实际上，因为萌学园被萨姆族不知名地洞入侵后，安保系统就进行了全面的升级，对学生、老师以及外来人员的审查机制愈发严苛。
至于地洞的形成原因，基本可以断定，是艾河馆手下使用的隐身巫术，利用了萌学园校庆这个时间点，前往萌学园施咒，而后造成的重大事件。
其动机，据艾河馆本人说明，是为了扰乱夸克族，让其无法在艾河馆统治宇宙期间有什么“非分之举”。但是，他本人也不清楚地洞魔法最终会通向何处，只是短暂的影响萌学园的教学秩序。
通过此次事件，萌学园已经能够很好的“揪出”隐身、化形、窥视等魔法（或巫咒）的使用，在安全方面有了很大的提升，老师和学生更加的放心了。
至于巡逻机制，鉴于地洞事件产生的一系列后续事件十分严重，为了防患于未然，长老会与萌学园进行了双防联动机制，即长老会“监视设备”与萌学园巡逻机制。
监视设备主要检查的是是否有可疑人员，会在每一个进出场所对人员进行自动身份检测，且设备隐藏，学生本人并不会发现；
巡逻机制就是在早上、中午和傍晚分别进行三次辅助身份检测及环境因素检测，配有长老会专用的“卧底透棒”进行扫描，能够很好的发现潜在的危险。
巡逻人员为校长、老师和部分自愿的学生，且为了防止渗透进巡逻人员中，启动巡逻设备前会自动核对本人身份和潜在漏洞。
今天，便轮到了帕主任巡逻。
他一眼就看到了潼恩，然后靠近了她，潼恩也发现了他。
“帕主任。”她站了起来，然后微笑着。
帕主任望向了四周，然后说。
“潼恩呐，诶，怎么就你一个人在这里啊。”
“哦，艾瑞克他们去焰王宿舍里叫他们了。想着今天是毕业课题汇报，所以就早点起来了。”
帕主任摸了摸头发。
“毕业课题汇报？哦哦哦，是今天啊，我都忘记了。（看了一下魔法沙漏）现在是六点半，毕业课题组我估摸着也得要九点才会来吧。”
“毕竟是毕业课题汇报，所以还是要稳固一下，早点起来也能够更加从容。”
“说的也是，那你就在先待在这吧，等艾瑞克他们来。”
潼恩点了点头，然后和帕主任说了再见。帕主任离开了，潼恩便继续坐在位置上了。
彼时，焰王和欧趴依旧躺在床上。
谜亚星直接上手掀开了焰王和欧趴的被子。
欧趴醒了并坐了起来，揉了揉眼睛，而后看到了谜亚星，等待片刻后才想起来有正事要干。
焰王此时也被弄醒，汉斯格雅却睡的和猪一样。
“你们终于醒了，怎么你们怎么叫都叫不醒啊。”艾瑞克说。
“别提了，昨天晚上汉斯格雅差点要把房子给掀了。你说，明明是睡着的，嘴巴里还在说话，说出来的话，就跟别人和他在吵架一样，悉悉索索个没完。我们叫了他很多次，他就是不改。没办法，折腾到后半夜，也就困个没完直接睡了过去。（打了个哈欠）”欧趴边穿衣服边说。
“是啊，有的时候，我真想一把火烧了他，这样，就睡过去了。”焰王摩拳擦掌，坐了起来。
“焰王。”艾瑞克说。
“确实奇怪哦，汉斯格雅之前应该没有说梦话的习惯吧，怎么昨天晚上就能把你们吵得睡不着。”谜亚星扶着下巴思考。
“先别管这么多了，潼恩还在穿堂等着，你们先收拾吧，等会直接去穿堂。”艾瑞克招呼谜亚星，直接从门口出去了。
而焰王和欧趴则以一种非常快的速度收拾好，也出门去了。
只留着汉斯格雅还在呼呼大睡。
（医疗室|保健室）
此时，保健室里大甜甜还在撰写教师资格评定报告，这是每一位教师都需要上交的，用来阶段性评定是否还能承担得起教师这个职称。
至于大甜甜，她本次撰写的报告为《学生在心理方面影响魔法能力的通用概述（黑夸和平、萨姆族事件）》。
她写着写着，犯起了难。
“吼哟，样本数量还是太少了，我们学校的同学啊，都太保守了，选取的样本还不典型。可是，还有三天就要上交了，维多利亚老师已经去长老会报告了，赛达康教授也稀里糊涂的写完了。就差我，这该如何是好啊。”
她犯嘀咕的时候，陶喜儿从门口进来。
“大甜甜老师。”
“嗯，怎么了（看向了陶喜儿）？”
“这里有一封从夸特诺基地寄来的信，是亮晶晶阿姨写的。”
“啊！晶，她写什么了。”她站了起来，然后接过了信。
“我也不知道，我没拆开来看。”
大甜甜将信迅速拆了开来，下面是这封信的原文：

亲爱的甜：
许久未写信了，看来是有点生疏，不过还好。
甜，我来夸克星环星调查局已经有好几天了，不过有一件事情非常非常难办，可能需要你的帮忙。因为这需要在疗愈方面有建树的专家，我第一个就想到了你。别问我为什么没想到陶不了，他快忙透了。
至于具体是什么事情呢，还是得你亲自来看看比较好。还有哦，记得带一点防晒的东西，这里可能有点晒。
好了，如果你能前来的话，一定要传讯给我。

晶

“她还是这样，连字都写得这么迅速。”大甜甜沉浸在亮晶晶写的信中，不过她很快就反应了过来。“哎呀，不对不对，我还有报告没写完呢，这下该如何是好啊。”
陶喜儿看到了大甜甜的面露难色，然后开始提起了建议。
“大甜甜老师，你可以派欧趴去啊，欧趴最近不是写完毕业课题汇报的嘛，还需要一个实践机会，这不是刚刚好吗？”
“说得对诶，我这就去联系欧趴。（又想起了什么事情）不过，陶喜儿，你的转学手续办的怎么样了。”
陶喜儿有些许的尴尬，她走到了大甜甜面前。
“大甜甜老师，你知道的，我不想离开萌学园。”
大甜甜走向了陶喜儿旁边。
“老师知道，你舍不得这里，不过，在魔系教育所里面你可以得到更好的发展，我们这里会让你受到限制。那里更安全，也更适合你。更重要的是，它就在夸克星上面，你可以随时随地见到焰王啊，还有陶格长老、亮晶晶阿姨。”
“我其实不是担心这个，反而我很期待。但……”
“好了，我们家陶喜儿最听话了，老师没事的，如果你担心换了环境不适应，可以再待几天。”大甜甜拍了拍陶喜儿的肩膀。
“大甜甜老师。”陶喜儿抱了大甜甜。
“好了好了，乖。”
两人就这么一直抱着，因为对陶喜儿来说，换了新的学校就意味着完全陌生，经营着的所有经验都要重来，老师、同学、朋友，还有这些，美好的记忆。

（校长室）
萌骑士五人已经集结完毕，毕业课题组已经有部分组员来到了办公室。
罗博高校长已经等候多时。
“校长。”萌骑士向罗博高打了招呼。
“你们来了。”罗博高看向了朝气蓬勃的大家。“嗯，看样子，大家都非常的自信。这样很好，很好。”
“介绍一下，这些是毕业课题组的专业老师，这是冷淋教授，是自然系的；这位是康达斯教授，是疗愈系的；哦，还有这位，这位是实习生老师，哈宇维克，他会监督你们的完成毕业汇报。现在还不到汇报时间，我们还要等一个人。”
说时迟，那时快。这位老师“传送”了过来，突然出现在了大家的面前。
“各位好。”这把大家都给吓了一跳。“不要紧张，我是毕业课题组组长，可以叫我恬教授。是超能力系的。”
“恬教授好！各位教授好！老师好！”萌骑士向四位教授和老师说了声好。
“嗯，大家就不要站着了，毕业课题大家都已经准备好了的话，就开始汇报吧。”罗博高招呼着大家。
为了让萌骑士能很好的汇报，校长室已经改变了样貌，有一块黑板，五个专职人员（3+1+1，三位主课题组，一位实习生老师，还有一位校长）坐在他们的面前。有个沙发供待汇报萌骑士准备。
紧接着，井然有序的毕业汇报就开始了。
他们所选取的课题，都是依托自身的魔法能力与未来流行趋势为模板，都是很有意义的。
在各位汇报完时，对应的教授进行了分析与提出了很好的建议。
经过了较为漫长的时间，汇报也结束了，五位老师对此都很满意，对他们表示啧啧赞叹。
“不错，不愧是夸克族的未来之星。”恬教授总结概括。“希望你们能够带领夸克族，带领整个宇宙，走向大同时代，稳定，一定要稳定住。哈哈。”
“谢谢各位老师。”萌骑士鞠了个躬。
“好了，大家的毕业课题汇报还是很不错的。大家先去休息休息吧。”罗博高指挥大家去休息，萌骑士再次鞠躬，表示感谢。
毕业课题汇报一旦完成，毕业就被提上了日程，也标志着大家即将迎来新的故事。
