岁窦工具箱 · 帮助文档

新手教程 · 常见问题 · 工具小贴士 · 快捷键 · 数据说明
版本：V2.1 正式版（2026.10）

一、快速开始

  1. 找到你要的工具：在首页的「热门工具」「分类」或「全部应用」里点击任意卡片，就能进入对应的工具页面；点击工具页左上角的「← 返回首页」可以随时回到首页。
  2. 用搜索框快速定位：顶部搜索框支持按工具名称和关键词检索。输入「记账」「词频」「日历」等词，首页会自动筛出相关工具；清空搜索框即可恢复完整列表。
  3. 不登录也能直接使用：默认是「本地模式」，所有数据保存在你自己的浏览器里，不需要注册。文章分析、计算器、统计图、时钟、画布、代码编辑器、小说助手等都不需要登录。
  4. 登录后开启云端同步与 AI：点击右上角「登录」注册账号后，数据会同步到云端，换设备登录同一账号即可继续使用；AI 助手、AI 润色、AI 生成简介等能力也只对登录用户开放。
  5. 养成备份的习惯：在「设置 → 数据管理」里点「导出全部数据（JSON）」即可下载一份完整备份。清除浏览器缓存或更换设备前，建议先导出一份。

二、常见问题

Q1. 数据保存在哪里？会不会丢？

不登录时，所有数据保存在你浏览器的 localStorage 中（键名以 suidou- 开头），刷新或关闭页面都不会丢失。
但清除浏览器缓存、更换设备 / 浏览器、使用无痕模式都会导致数据丢失，建议定期在「设置 → 数据管理」导出 JSON 备份。

Q2. 换了一台设备，怎么把数据搬过去？

  • 方式一（推荐）：注册并登录账号 → 在设置页点「上传本地数据到云端」→ 另一台设备登录同一账号后点「从云端拉取数据」。
  • 方式二：在旧设备导出 JSON 备份文件，在新设备通过「设置 → 导入数据」恢复。

Q3. 本地模式和云端模式有什么区别？

  • 本地模式：数据只存在你自己的浏览器里，不上传服务器，无需登录，适合单设备使用。
  • 云端模式：登录后数据同步到 Supabase，多设备共用同一份数据；AI 相关功能也只对登录用户开放。

右上角的徽章会实时显示当前所处的模式。

Q4. 为什么 AI 功能提示「请先登录」？

AI 请求需要通过你的登录凭证转发到服务端进行鉴权和额度统计，因此必须先登录才能使用。登录后每天有固定的免费额度，聊天页右上角会显示「今日已用 x / 20 次」。

Q5. AI 每天能用多少次？额度什么时候重置？

每个账号每天有固定的免费调用次数，AI 助手聊天页会实时显示今日已用次数。额度按自然日重置，当天的使用量不会累计到第二天。

Q6. 忘记密码了怎么办？

在登录页点击「忘记密码？」，输入注册邮箱后我们会发送一封重置密码的邮件。如果没收到，请检查垃圾邮件文件夹；重置链接有时效，过期后可以重新发送。

Q7. 怎么修改用户名和头像？

登录后进入「设置 → 个人资料」，可以上传头像（自动压缩到 180px 以内）和修改用户名。用户名只用于主页右上角显示，不影响登录邮箱；未登录时这两项不可用。

Q8. 上传的图片会不会占用很多空间？

所有图片在上传前都会自动压缩：头像 180px、人物图片 400px、小说封面 600px、地点与影视图片 800px。浏览器 localStorage 上限一般约 5 MB，可在「设置 → 数据管理」查看当前占用。

Q9. 歌曲收藏能直接试听吗？

不能。本工具只记录歌曲信息与歌词，并提供 QQ音乐、酷我音乐、酷狗音乐、网易云音乐的搜索 / 直链跳转，播放需要到对应平台进行。

Q10. 日历为什么只能查看 2026 年 10 月到 2036 年 12 月？

这是当前版本设定的可查看范围，超出范围的月份在年份 / 月份下拉框中会被禁用。点击「回到 2026-10」可以快速回到起点。

Q11. 代码编辑器安全吗？支持哪些语言？

JavaScript 模式运行在带有 sandbox 属性的 iframe 中，无法访问本页面的数据和存储，相对安全。当前支持 JavaScript 实时运行 与 Markdown 实时渲染两种模式。

Q12. 点了导出按钮却找不到文件？

所有导出都通过浏览器的下载功能保存到默认下载目录。如果没有反应，请检查浏览器是否拦截了下载、是否开启了「下载前询问保存位置」。

Q13. 误删或清空的数据还能恢复吗？

不能。工具箱不保存历史版本，已清空且没有备份的数据无法找回。执行「清空全部数据」之前请务必先导出备份。

Q14. 页面显示异常、按钮点不动怎么办？

可以依次尝试：① 刷新页面；② 检查网络；③ 换用 Chrome / Edge / Safari 等现代浏览器。

三、工具小贴士

  • 文章分析：字数统计按字符计算，中文、英文字母、数字、标点分别归类；词频分析的中文按双字组切分。
  • 小说助手：支持章节分类（前言 / 正文 / 番外 / 附录 / 后记 / 作者的话）、字数统计图，可导出 TXT 与 HTML。
  • 人物印象表 / 影视收藏：支持 AI 生成小传 / 简介，结果可一键插入表单。
  • 地点收藏：国内填到具体门牌号，国外写到城市或地标即可。
  • 我的日历：点击日期格子添加安排，支持导出当月图片。
  • 我的记账本：多币种，按币种汇总，可导出 CSV。
  • 畅想画布：支持鼠标与触屏书写，导出 1400 × 900 高清 PNG。
  • 代码编辑器：JavaScript 沙箱运行，console.log 输出显示在预览下方；Markdown 实时渲染。

四、快捷键速查

场景 按键
计算器 0-9 + - * / ( ) . % ^；Enter / = 求值；Backspace 退格；Esc 清空
代码编辑器 Tab 缩进两个空格；Ctrl / ⌘ + Enter 立即运行或渲染
AI 聊天 Ctrl / ⌘ + Enter 发送消息

五、数据与隐私

  • 本地模式：数据保存在浏览器 localStorage，不上传服务器，上限约 5 MB。
  • 云端模式：登录后通过 Supabase 同步，密码由 Supabase Auth 加密处理。
  • 图片压缩：头像 180px、人物 400px、小说封面 600px、地点与影视 800px。
  • 导出格式：JSON、CSV、docx、TXT / HTML、PNG。
